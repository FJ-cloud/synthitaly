The model writes nothing to disk on its own. model.py:936-938 is explicit about it — callers decide what to persist. So “dataset” here means a table the model hands you; where it ends up is a choice made by a notebook or a script. The persistence status of each is stated in its section.
There are no input datasets. The active model reads no external file at all — every empirical figure is a paper-cited constant in src/synthitaly/numbers.py. That is unusual enough to state plainly: reproducing these tables needs the code and a seed, nothing else.

Appendix

How the tables reconcile

Four independent views of the same run. They agree, and the agreement is tested:

IdentityMeaningTested by
Σ all balances = Σ all opening balancesmoney is conserved system-wide — every movement is a paired debit and credittests/test_conservation.py
account balance = starting_balance + total_in − total_outeach account reconciles against its own statement linestests/test_smoke.py
Σ ledger amount_eur by household ≈ statement lines minus sweepsthe ledger is the statement without the internal transfersby construction — see Dataset 1
feature frame ⊂ ledger + accountsno feature reads agent internals except the quarantined blockstests/test_analysis_pipeline.py
Interest is the one movement with no row anywhere. It increments debt_balance directly. That is what lets debt grow while money still conserves — the principal is a claim, not cash, and no cash moves when it accrues.
